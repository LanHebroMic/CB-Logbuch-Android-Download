# CB-Logbuch Android

Ein mobiles, lokales Logbuch für CB-Funker und Funkamateure, entwickelt mit Python und dem Flet-Framework. Diese App ermöglicht eine schnelle und unkomplizierte Dokumentation von Funkkontakten (QSOs) direkt auf dem Smartphone.

## Hauptfunktionen

*   **QSO-Logging:** Erfassung von Skip/Rufzeichen, Standort (Locator), Frequenz (RX/TX), Rapporten (R/S) und Betriebsart.
*   **Intelligente Ländererkennung:** Automatische Zuweisung von Ländern basierend auf Amateurfunk-Präfixen oder internationalen CB-Divisionen.
*   **Distanzberechnung:** Automatische Berechnung der Entfernung zum Funkpartner bei Eingabe beider QTH-Locatoren.
*   **Archiv & Suche:** Durchsuchen der letzten 50 QSOs nach Skip, Locator oder Land.
*   **Datenbank-Management:** Unterstützung für mehrere Datenbank-Dateien, Erstellen neuer Logs und Löschen alter Bestände.
*   **ADIF Export:** Export der Logdaten im Standard-ADIF-Format zur Verwendung in externen Programmen.
*   **Echtzeit-UTC:** Integrierte UTC-Uhr für präzise Zeitangaben im Funkbetrieb.

## Installation & Build

Die App wird als Android APK gebaut.

## Datenschutz

Sicherheit und Privatsphäre stehen im Vordergrund. Alle Daten werden ausschließlich in einer lokalen SQLite-Datenbank auf dem Endgerät gespeichert.
